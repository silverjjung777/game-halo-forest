# 헤일로: 숲의 비밀

천사 루미와 악마 루아가 함께 숲을 건너 작은 뱀을 물리치고, 초록 워프를 통해 거대 뱀 녹스에게 도전하는 WebGL 협동 플랫폼 게임입니다. 시작 제목은 사용자가 제공한 ‘헤일로 숲의 비밀’ 로고입니다.

## 세 개의 맵

1. 빛의 숲: 기존 첫 번째 배경.
2. 폭포의 정원: 새로 제공한 숲 배경. 계단형 섬·다리에 맞는 별도 충돌 지형이며, 첫 맵 오른쪽에서 연결 발판과 함께 이어집니다. 맨 오른쪽 초록 워프에 들어가거나 ↑를 누르면 두 캐릭터가 함께 보스 맵으로 이동합니다. 협동 모드에서는 두 친구가 워프 가까이 모여야 합니다.
3. 녹스의 둥지: 새로 제공한 어두운 숲 배경. 왼쪽에 파란 도착 워프가 있고, 그림의 석조 발판을 건너 오른쪽 보스에게 갑니다. 보스 처치 후에는 폭포의 정원으로 돌아갈 수 있습니다.

## 시작과 조작

시작 화면에서 `1인 + 동료 AI` 또는 `2인 협동`을 고른 뒤 1P 캐릭터를 선택합니다. 다른 캐릭터는 AI 또는 2P가 맡습니다. 2인은 같은 기기·키보드에서 플레이하며 온라인 멀티플레이는 아닙니다.

| 동작 | 1P | 2P |
|---|---|---|
| 좌우 이동 | ← / → | A / D |
| 점프 | Space | F 또는 W |
| 공격 | P | G |
| 발판 아래로 | ↓ | S |
| 동료와 대화 / 다음 대화 | E (또는 대화 중 Enter) | 공용 E |
| 일시정지 | Esc | 공용 Esc |

P/G는 길게 누르면 쿨다운마다 연속 공격합니다. 천사는 별을, 악마는 불꽃을 쏩니다. 앞쪽 가까운 적의 높이에 맞춰 조준을 보조합니다. 1인 모드 동료는 플레이어의 지나온 경로를 따라오며 적을 자동 공격합니다. 두 플레이어가 너무 멀어지면 같은 화면에 머물도록 이동 범위를 제한합니다.

## 전투와 성장

- 작은 뱀 처치: 팀 점수 +100. 보스 처치: +1,000.
- 레벨 점수: 0 / 200 / 500 / 900 / 1,400 / 2,100 / 3,000.
- 탄환당 공격력: 10 / 16 / 24 / 34 / 46 / 60 / 78.
- Lv.3부터 2연발, Lv.5부터 3방향 공격.
- 빛 수집·체크포인트·레벨업은 살아 있는 캐릭터의 체력을 회복합니다.
- 한 명이 쓰러져도 동료가 4초 버티면 체력 3으로 돌아옵니다. 둘 다 쓰러지면 마지막 체크포인트에서 점수·공격력을 유지한 채 재도전합니다.
- 보스는 **눈 명중 한 발이면 즉시 처치**, 또는 **몸통 어디든 실제 탄환 20발 명중하면 처치**됩니다. 레벨에 따른 공격력은 작은 뱀에게 적용되며 보스의 요구 명중 수는 바뀌지 않습니다. 이미지의 투명한 부분은 몸통 명중으로 세지 않습니다.
- 1P는 점프하면서 ↑+P로 눈을 조준할 수 있습니다. 2P는 W로 점프·위쪽 조준을 하며 G로 공격합니다.
- 몸통 10회 명중 이후에는 보스의 공격 간격이 짧아지고 3방향 탄환을 사용합니다.
- 승리하면 두 캐릭터가 실제 정면·미소·양손 V자 스프라이트로 바뀌어 반복 만세 점프를 합니다. 결과 패널은 왼쪽에 표시해 캐릭터를 가리지 않습니다.

## 실행

### Vercel 배포

이 저장소를 Vercel에서 Import하면 루트의 `vercel.json` 설정을 사용합니다.

- Framework Preset: **Other**
- Root Directory: 저장소 루트 (`.`)
- Build Command: `npm run build`
- Output Directory: `public`
- 환경 변수·API 키·데이터베이스: 필요 없음

런타임 및 배포 빌드에는 외부 npm 의존성이 없습니다. 큰 그림은 WebP로 최적화했고 픽셀 캐릭터는 원래의 투명 PNG를 유지합니다. 빌드에서 JS·CSS·이미지 파일명에 내용 해시를 붙여 장기 캐시를 사용하고, HTML은 재검증하도록 설정합니다. 오프라인 단일 HTML·검증 스크린샷·원본 대용량 PNG·개인 Sites 설정은 배포 결과에 포함하지 않습니다.

로컬 프로덕션 미리보기: `npm run build` 후 `npm run dev` 실행, `http://127.0.0.1:8766` 접속.

기본 검사: `npm test`. 전체 게임 흐름 검사: Python 3와 Pillow를 설치한 뒤 `npm run test:game` (필요하면 `HALO_PYTHON` 환경 변수로 Python 실행 파일 지정).

`npm run build:local`로 생성하는 `play.html`은 모든 에셋을 포함한 단일 파일이므로 브라우저로 바로 열 수 있습니다. Windows에서는 `play.cmd`를 실행해도 됩니다. 생성한 단일 파일은 중복 이미지가 들어가므로 Git 및 Vercel 배포 대상에서는 제외합니다.

개발 시 `dist/`를 정적 HTTP 서버로 제공합니다. 예: `python -m http.server 8765 --directory dist`. 코드의 원본은 `dist/engine.js`, `adventure.js`, `adventure.css`, `index.html`입니다. 이전 단독 모험의 `game.js`는 새 페이지에서 로드하지 않습니다.

## 에셋과 검증

숲·작은 뱀·보스는 사용자가 제공한 PNG를 사용합니다. 천사와 악마는 sprite-gen 3.5.0 / GPT의 방향 앵커→달리기 행→추출→아틀라스 파이프라인으로 제작했습니다. 두 캐릭터 모두 96×112 셀, idle4@5fps, run8@12fps이며 절대 프레임 좌표와 nearest filtering을 사용합니다. 좌측은 런타임 미러입니다. 달리기는 4단계 반복이 남는 프로토타입 모션입니다.

2인 원형은 실제 브라우저 키 입력으로 캐릭터 선택·동시 이동/점프/공격·작은 뱀 처치·레벨업·보스 처치·대화를 검증했습니다. 현재 공격 키는 1P P / 2P G입니다. 최신 세 맵·워프·승리 모션은 `test-adventure.cjs`가 실제 게임 스크립트를 실행해 입력을 시뮬레이션하며, 새 두 번째 맵의 섬 경로, 초록 워프, 보스 맵 왼쪽 도착, 보스 발판 경로, 실제 탄환 충돌, 두 정면 승리 아틀라스의 반복 점프, 오디오 컨텍스트 0개를 검사합니다. 최신 버전의 브라우저 전체 재검증은 자동 제어 연결 지연으로 완료하지 못했습니다.

큰 그림 8장의 용량은 19,196,926바이트에서 3,087,120바이트로 약 84% 줄었습니다. Vercel용 빌드 결과는 약 3.08 MiB이며 파일 내용 해시에 따른 장기 캐시를 적용합니다.

보스 규칙은 `node test-boss-rules.cjs`로 19회 생존, 20회 승리, 첫 눈 명중 승리, 빗나간 탄환, 이미 죽은 보스, 프레임 사이 눈 통과 판정을 검사합니다.

게임은 로컬에서 실행하며 외부 업로드·배포는 하지 않았습니다. 기본 상태에서는 오디오 컨텍스트를 만들거나 재생하지 않습니다. 사용자가 직접 소리 켜기를 선택해야만 음향이 켜집니다.
